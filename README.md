# بلوت

لعبة بلوت سعودية لأربعة لاعبين، تشتغل من المتصفح بدون سيرفر.

## طريقة اللعب
1. واحد منكم (المضيف) يفتح الصفحة ويضغط **أنشئ طاولة**.
2. يطلع له كود ورابط، يرسله لأصحابه.
3. الباقين يفتحون الرابط (أو يدخلون الكود)، وكل واحد يجلس على كرسي، وبعدها **ابدأ اللعب**.

## تنبيهات
- اللعبة تشتغل في جهاز المضيف، فخلّ الصفحة مفتوحة عنده طول اللعب. إذا طلع منها أو قفل الشاشة، الطاولة توقف وتكمل لما يرجع.
- الاتصال بين الأجهزة مباشر (WebRTC عن طريق PeerJS). بعض الشبكات (مثل شبكات الشركات أو بعض شبكات الجوال) ممكن تمنعه.
